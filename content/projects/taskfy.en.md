**Node.js · TypeScript · Drizzle ORM · PostgreSQL · Vue 3**
**2026**

- Architected a full-stack ecosystem inspired by Jira, focused on high cohesion and low coupling, using a modular structure for feature scalability.
- Developed a reactive Time Tracking engine with persistent time logs and real-time workload balance calculations through advanced SQL and Drizzle ORM.
- Implemented a hierarchical permissions system (RBAC) for Teams and Projects, guaranteeing that only supervisors and administrators can perform critical write and delete operations.
- Built a reactive Vue 3 interface with Pinia for global state management, using a Schedules system that automatically organizes tasks by due date proximity and priority.
